二期間モデル

次の二期間モデルを考える. この経済において, 質量1の若年期と質量1の老年期の個人が存在し, 各個人は個人の生産性 \(z\) に応じて, 労働時間 \(h\) と貯蓄 \(a\) を選択する. 個人の最適化問題は次のように表される.

\[ \max_{c_1, c_2, h, a} \frac{c_1^{1-\gamma}-1}{1-\gamma} - \psi \frac{h^{1 + 1/\eta}}{1 + 1/\eta} + \beta \frac{c_2^{1-\gamma}-1}{1-\gamma}, \] subject to

\[ c_1 + a = w z h, \quad c_2 = (1 + r) a + T. \] ここで, \(c_1, c_2 > 0\) はそれぞれ若年期と老年期の消費、\(h > 0\) は労働時間、\(a \in (-\infty, \infty)\) は貯蓄を表す. \(w > 0\) は賃金率、\(r > 0\) は利子率、\(T \ge 0\) は外生的な移転を表す. また, 個人の生産性 \(z\) は対数正規分布 \(\log z \sim \mathcal{N}(\mu, \sigma^2)\) に従って, 若年期の始めに外生的に与えられているとする. また, 分布の累積密度関数を \(F(z)\), 密度関数を \(f(z)\) とする. 企業は Cobb-Douglas 型の生産関数 \(Y = K^\alpha L^{1-\alpha}\) を持ち, 資本は完全減耗 (\(\delta = 1\)) する.1

数値問題では次のパラメータの値を用いる: \(\gamma = 2\), \(\eta = 0.5\), \(\psi = 2\), \(\alpha = 0.36\), \(T = 0.05\). 割引因子は年率を \(0.96\) とし, 1期間が約30年に相当するので \(\beta = 0.294\) を用いる. 生産性の分布は \(\mu = 0\), \(\sigma = 0.4\) とする (すなわち \(\log z \sim \mathcal{N}\left(0, 0.4^2\right)\)). ただし Exercise 2.2 の (d) では \(\gamma\) のみを変化させる.

Exercise 2.1 (Paper and Pencil Exercises)  

  1. 家計の最適化条件 (Inter- & Intra-temporal Conditions) を導出せよ. また, \(h\) を唯一の未知数として, \(c_1, c_2, a\) を表せ.

  2. 企業の利潤最大化問題を定義し, その一階条件を定義せよ. また, 賃金率 \(w\) と利子率 \(r\) を \(k := K / L\) として表せ.

  3. 資本市場と労働市場の均衡条件を定義せよ. なお, 若年期の個人のインデックスとして \(i \in [0, 1]\) を用いても良い.

Solution 2.1 (Solutions to Exercise 2.1).

  1. 生産性 \(z\) を持つ個人について、

\[ \max_{c_1,c_2,h,a} \frac{c_1^{1-\gamma}-1}{1-\gamma} -\psi\frac{h^{1+1/\eta}}{1+1/\eta} +\beta\frac{c_2^{1-\gamma}-1}{1-\gamma} \]

subject to

\[ \begin{align} c_1+a & =wzh, \\ c_2 & =(1+r)a+T. \\ \end{align} \]

という問題を考えます。 ラグランジュ関数を

\[ \begin{aligned} \mathcal L ={} & \frac{c_1^{1-\gamma}-1}{1-\gamma} -\psi\frac{h^{1+1/\eta}}{1+1/\eta} +\beta\frac{c_2^{1-\gamma}-1}{1-\gamma} \\ & +\lambda_1(wzh-c_1-a) +\lambda_2\bigl((1+r)a+T-c_2\bigr) \end{aligned} \]

と置きます。\(c_1\) について、

\[ \frac{\partial\mathcal L}{\partial c_1} = c_1^{-\gamma}-\lambda_1=0, \]

したがって、

\[ \lambda_1=c_1^{-\gamma}. \tag{2.1}\]

また、\(c_2\) について、

\[ \frac{\partial\mathcal L}{\partial c_2} = \beta c_2^{-\gamma}-\lambda_2=0, \]

したがって、

\[ \lambda_2=\beta c_2^{-\gamma}. \tag{2.2}\]

\(a\) について、

\[ \frac{\partial\mathcal L}{\partial a} = -\lambda_1+(1+r)\lambda_2=0. \]

Equation 2.1 と Equation 2.2 を代入すると、

\[ \left( \frac{c_2}{c_1} \right)^{\gamma} = \beta(1+r). \tag{2.3}\]

これが intertemporal condition（Euler equation） です。これは消費の成長率が利子率と割引因子によって決まることを意味します。

\(h\) について，

\[ \frac{\partial\mathcal L}{\partial h} = -\psi h^{1/\eta} +\lambda_1 wz =0. \]

Equation 2.1 を用いると、

\[ \psi h^{1/\eta} = wz c_1^{-\gamma}. \tag{2.4}\]

これが intratemporal condition です。左辺は追加的な労働の限界不効用、右辺は追加的な労働によって得られる所得 \(wz\) を消費の限界効用で評価したものです。

ここから、\(c_1,c_2,a\) をすべて \(h\) の関数として表します。Equation 2.3 より、

\[ c_2 = [\beta(1+r)]^{\frac{1}{\gamma}}c_1. \tag{2.5}\]

第2期の予算制約から、

\[ a=\frac{c_2-T}{1+r}. \]

これを第1期の予算制約に入れると、

\[ c_1+\frac{c_2-T}{1+r}=wzh. \]

したがって,

\[ c_1+\frac{c_2}{1+r} = wzh+\frac{T}{1+r}. \]

これは個人の lifetime budget constraint です。Equation 2.5 を代入すると,

\[ c_1+\frac{[\beta(1+r)]^{\frac{1}{\gamma}}c_1}{1+r} = wzh+\frac{T}{1+r}. \]

よって

\[ c_1(h;z,w,r) = \frac{(1+r)wzh+T} {1+r+[\beta(1+r)]^{\frac{1}{\gamma}}} \tag{2.6}\]

となります。Equation 2.5 より,

\[ c_2(h;z,w,r) = [\beta(1+r)]^{\frac{1}{\gamma}} \frac{(1+r)wzh+T} {1+r+[\beta(1+r)]^{\frac{1}{\gamma}}} \tag{2.7}\]

であり、\(a\) については \(a=wzh-c_1\) より

\[ a(h;z,w,r) = \frac{[\beta(1+r)]^{\frac{1}{\gamma}}wzh-T} {1+r+[\beta(1+r)]^{\frac{1}{\gamma}}}. \tag{2.8}\]

これで \(c_1,c_2,a\) はすべて \(h\) だけの関数になりました。

Note

残っている intratemporal condition \(\psi h^{1/\eta} = wz c_1^{-\gamma}\) に Equation 2.6 を代入すると、

\[ \psi h^{1/\eta} = wz \left[ \frac{(1+r)wzh+T} {1+r+[\beta(1+r)]^{\frac{1}{\gamma}}} \right]^{-\gamma}. \]

したがって、最適労働時間 \(h^\ast\) は

\[ \psi h^{1/\eta} \left[ \frac{(1+r)wzh+T} {1+r+[\beta(1+r)]^{\frac{1}{\gamma}}} \right]^\gamma -wz =0 \]

を満たします。したがって数値計算では

\[ G(h;z,w,r) := \psi h^{1/\eta} \left[ \frac{(1+r)wzh+T} {1+r+[\beta(1+r)]^{1/\gamma}} \right]^\gamma-wz \]

を定義し、\(G(h;z,w,r)=0\) を1変数の root-finding で解けばよいことになります。しかも \(h>0\) について左辺第1項は単調増加するため、正の解は一意です。\(h^\ast\) が求まれば、Equation 2.6, Equation 2.7, Equation 2.8 から \(c_1^\ast, c_2^\ast, a^\ast\) が求まります。

  1. 企業の利潤最大化問題を定義し, その一階条件を定義せよ. また, 賃金率 \(w\) と利子率 \(r\) を \(k := K / L\) として表せ.

企業の生産関数は

\[ Y=K^\alpha L^{1-\alpha}. \]

資本 \(K\) を1単位保有した場合の家計への gross return は

\[ 1+r \]

です。一方、企業側から見た資本の収益は

\[ F_K+1-\delta \]

です。

したがって均衡では一般に

\[ 1+r=F_K+1-\delta. \]

が成立します. 今回は \(\delta=1\) なので、

\[ 1+r=F_K. \]

つまり資本は期末に完全に消滅するため、資本の限界生産物そのものが gross return になります。したがって企業の利潤最大化問題は、

\[ \max_{K,L} K^\alpha L^{1-\alpha} -wL-(1+r)K. \]

一階条件は、まず \(L\) について

\[ (1-\alpha)K^\alpha L^{-\alpha}-w=0, \]

したがって

\[ w=(1-\alpha)K^\alpha L^{-\alpha}. \]

資本については

\[ \alpha K^{\alpha-1}L^{1-\alpha}-(1+r)=0, \]

したがって

\[ 1+r = \alpha K^{\alpha-1}L^{1-\alpha}. \]

ここで

\[ k:=\frac{K}{L} \]

と定義します。すると、

\[ K^\alpha L^{-\alpha} = \left(\frac{K}{L}\right)^\alpha = k^\alpha \]

なので、

\[ w(k) = (1-\alpha)k^\alpha. \]

また、

\[ K^{\alpha-1}L^{1-\alpha} = \left(\frac{K}{L}\right)^{\alpha-1} = k^{\alpha-1} \]

なので、

\[ 1+r = \alpha k^{\alpha-1}. \]

したがって

\[ r(k) = \alpha k^{\alpha-1}-1. \]

  1. 資本市場と労働市場の均衡条件を定義せよ. なお, 若年期の個人のインデックスとして \(i \in [0, 1]\) を用いても良い.

生産性 \(z\) は

\[ \log z\sim\mathcal N(\mu,\sigma^2) \]

に従います。価格 \((w,r)\) が与えられると、各生産性 \(z\) の家計は

\[ h(z;w,r),\qquad a(z;w,r) \]

を選びます。 生産性 \(z\) の個人が \(h(z)\) 時間働くと、その労働投入は \(zh(z)\) です。したがって総労働供給は

\[ L^s(w,r) = \int_0^\infty z h(z;w,r)f(z) dz. \]

労働市場均衡は

\[ L = \int_0^\infty z h(z;w,r)f(z) dz. \]

若年期の個人のインデックスを \(i\in[0,1]\) で表すと

\[ L = \int_0^1 z_i h_i di. \]

若年世代が行った貯蓄が、次期の企業の資本になります。よって、

\[ K' = \int_0^\infty a(z)f(z) dz. \]

定常均衡では

\[ K = \int_0^\infty a(z;w,r)f(z) dz. \]

\(i\in[0,1]\) を用いれば、

\[ K = \int_0^1 a_i di. \]

したがって、価格 \((w,r)\) に対する家計側の aggregate capital supply と aggregate labor supply は

\[ K(w,r) = \int_0^\infty a(z;w,r)f(z) dz, \]

\[ L(w,r) = \int_0^\infty z h(z;w,r)f(z) dz. \]

となります。よってこのモデルの定常均衡は

\[ \left\{ h(z),c_1(z),c_2(z),a(z),K,L,w,r \right\} \]

であって、すべての \(z\) について家計の最適化条件

\[ c_1^{-\gamma} = \beta(1+r)c_2^{-\gamma}, \]

\[ \psi h^{1/\eta} = wz c_1^{-\gamma} \]

が成立し、企業について

\[ w=(1-\alpha)k^\alpha, \qquad 1+r=\alpha k^{\alpha-1}, \qquad k:=\frac{K}{L} \]

が成立し、市場清算条件

\[ K=\int_0^\infty a(z;w,r)f(z) dz, \]

\[ L=\int_0^\infty zh(z;w,r)f(z) dz \]

が成立するものです。

三期間モデル

次の三期間モデルを考える. 家計は3期間にわたって消費と貯蓄を決定する (労働は \(h = 1\) で固定されているとする). \(t = 1, 2\) に働き, \(t = 3\) は引退して消費のみを行う. 家計の最適化問題は次のように表される.

\[ \max_{c_1, c_2, c_3, a_1, a_2} \sum_{t=1}^{3} \beta^{t-1} \frac{c_t^{1-\gamma} - 1}{1 - \gamma} \] subject to \[ \begin{aligned} c_t + a_t &= (1 - \tau) w_t + (1 + r) a_{t-1} & \text{ if } t = 1, 2, \\ c_3 &= (1 + r) a_2 + T & \text{ if } t = 3. \end{aligned} \] なお, \(a_0 = 0\) とする. ここで, \(c_t\) は期間 \(t\) の消費, \(a_t\) は期間 \(t\) の貯蓄である. また, \(\beta\) は割引因子, \(r\) は利子率である. 政府は就労世代 (\(t = 1, 2\)) の労働所得に比例税率 \(\tau\) を課し, その税収で退職世代 (\(t = 3\)) への一律の移転 \(T\) を賄う. 財政は毎期均衡する (税収 = 移転総額). 個人の賃金 \(w_t\) は次の AR(1) 過程に従うとする.

\[ \begin{aligned} \log w_1 &= \varepsilon_1, \quad \varepsilon_1 \sim N(0, \sigma_1^2), \\ \log w_2 &= \rho \log w_1 + \varepsilon_2, \quad \varepsilon_2 \sim N(0, \sigma_2^2). \end{aligned} \] 企業は生産関数 \(Y_t = K_t^{\alpha}\) をもち, 資本は完全減耗するものとする.

数値問題では次のパラメータの値を持ちいる: \(\gamma = 2\), \(\alpha = 0.36\). 割引因子は年率を 0.96 とし, 1期間が約20年に相当するので, \(\beta = 0.44\) とする. 賃金に関するパラメータは \(\rho = 0.9\), \(\sigma_1 = 0.4\) とする. 所得税率は \(\tau = 0.20\) とし, 移転 \(T\) は政府の均衡予算 (税収 = 移転) から内生的に決まる.

  2. \(a_2\) を唯一の未知数として, \(c_1, c_2, c_3, a_1\) を \(a_2\) の関数として表せ.

  3. 資本市場の均衡条件を定義せよ. また, 政府の均衡予算条件 (税収 = 移転総額) から, 移転 \(T\) を税率 \(\tau\) と賃金分布を用いて表せ. なお, 1期の賃金の累積密度関数を \(F_1(w)\), 2期の賃金の条件つき累積密度関数を \(F_2(w|w_1)\) と表してよい.
