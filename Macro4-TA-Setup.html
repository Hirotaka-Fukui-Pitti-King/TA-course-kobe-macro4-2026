Quarto、Julia、VScodeの準備

Quarto、Julia、VScodeの準備

Quarto、Julia、VScodeをPC上で使うための準備をしていきます。

  • WindowsとMacを例に解説していきます。

流れとしては

  • Julia のインストールと基本設定
  • Quarto 環境の構築
  • VSCode での統合開発環境（IDE）の設定
  • Julia + Quarto + VSCode の連携確認

という感じです。

Windows

Julia

ダウンロードととインストール

juliaupという Julia の公式インストーラ兼バージョンマネージャから入手するのが簡単です。

  1. Microsoft Storeの Julia アプリページ にアクセス
  2. 「入手」ボタンを押すだけで juliaup がインストールされます
  3. PowerShell を開き、次で確認：
juliaup status

「default: release」と表示されればOKです。

PowerShell から直接インストールすることもできます。

winget install julia -s msstore

とPowerShellで入力してください。

別の方法として公式サイトから直接入手することもできます。

推奨はStable Release版 (2025年10月6日現在では Julia 1.11.7)

  1. Windows (64-bit もしくは32-bitのInstaller) を選択します。
  2. インストーラを起動し、「Add Julia to PATH」にチェック

powershellで

julia

と入力し実行するとJulia REPL（対話環境）が開きます。そして

julia> versioninfo()

を入力し、バージョン情報が表示されればJuliaのインストール成功です。

Quarto

ダウンロードとインストール

公式サイトからダウンロードします。

  1. Quartoの公式サイトからWindowsを選択してダウンロードします。

うまくインストールできていれば、PowerShellで

quarto check

を実行すると

[✓] Checking Quarto installation......OK
[✓] Checking Julia engine............OK

のような結果が返ってくるはずです。

VScode

Quarto+Juliaを動かす環境はいろいろありますが、今回はVScodeを使います。

ほかのものが使いたい場合はQuartoの公式サイトを参照してください。

ダウンロードととインストール

  • Visual Studio Code公式サイトよりWindows版を選択してダウンロード。

拡張機能(Extensions)の導入

おすすめ拡張機能

  • “Julia”: Julia 実行の補助
  • “Quarto”: Quarto (.qmd) の補助
  • “Markdown All in One”: Markdownの書式補助

インストール方法: Ctrl+Shift+X → 検索バーで拡張機能名を入力 → Install

Juliaの動作確認

実行ファイル作成

  1. VSCode 左上の「新しいファイル」アイコンをクリック
  2. 右下で「言語モードを選択」→ Julia (Quarto)を選ぶ
  3. 名前をつけて保存（例：hello.jl）

hello.jl を作成して以下を記述：

Hello, Julia  from VSCode!

実行: 右上のRun ボタンで実行、Alt + Enter（選択部分を実行）または Ctrl + F5（全体実行）

Hello, Julia from VSCode!

と表示されれば成功。

Quartoの動作確認

せっかくなので

マクロIVでのテンプレート

を使って動作確認してみましょう。

リンク先からqmdファイルをダウンロードして自分のフォルダに置きます。

プレビュー Ctrl + Shift + Kまたは右上のpreviewボタンをクリック。

レンダー quarto render 00-answer.qmd

pdfが生成されるはずです。

  • M1 Macにhomebrewをインストールする（3.0.0版）

Homebrewのインストール

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# パスを通します
$ echo 'eval $(/opt/homebrew/bin/brew shellenv)' >> ~/.zshrc

インストール後、which brewで確認すると/opt/homebrew/bin/brewがインストール先として表示されるようです。

Julia

juliaupのインストール

Homebrewを使ってターミナルからインストール:

brew install juliaup

動作確認：

juliaup status

Juliaを起動して確認：

julia

julia version 1.12.x のような表示が出れば成功です。

Quarto

インストール

ターミナルで

brew install quarto

と打ち込むかもしくは公式サイトからインストーラをダウンロードしてもOKです。

インストール後に

quarto check

と打って

[✓] Checking Quarto installation......OK
[✓] Checking Julia engine............OK

のような結果が返ってくれば大丈夫です。

VScode

  1. VScodeの公式サイトに行き、リンゴのマークのものを選びます。
  2. ダウンロードフォルダからVSCodeのファイルを選び、クリックします。
  3. アイコンが作られるのでそれをドラッグ&ドロップでサイドメニューのアプリケーションに移動させます。
  4. サイドメニューのアプリケーションから開きます。

拡張機能(Extensions)の導入

おすすめ拡張機能

  • “Julia”: Julia 実行の補助
  • “Quarto”: Quarto (.qmd) の補助
  • “Markdown All in One”: Markdownの書式補助

インストール方法: ⌘ + Shift + X → 検索バーで拡張機能名を入力 → Install

そのあとの動作確認などはWindows版と同じです。
