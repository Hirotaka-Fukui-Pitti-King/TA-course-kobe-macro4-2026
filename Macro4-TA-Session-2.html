Julia入門

関数

基本的な定義方法

基本的に関数は

function 関数名(引数)
  return 戻り値
end

と書きます。引数は関数に対するインプットのことです。

例: 効用関数

γ = 0.5
function u(c)
    return (c^1-γ)/(1-γ)
end
u(2)
3.0

匿名関数（ラムダ式）

名前を持たない関数のことを「匿名関数 (ラムダ式)」と呼びます。

通常の関数は f(x) のように名前を付けますが、匿名関数は一時的に使うため名前を付けません。

plot()などの関数の中で関数を定義して使いたいときなどに使います。

x = [1, 2, 3, 4, 5]
plot(x, x -> x^2)

x -> x^2 は「入力 x を受け取り x^2 を返す関数」を表します。

キーワード引数（keyword arguments）

Julia の関数定義には、

  • 位置引数（普通の引数）
  • キーワード引数（名前付きのオプション）

の2つが引数として用意されています。

function f(x; a=1, b=2)
    return a*x + b
end
f(3; a=10)     # a=10, b はデフォルト 2
f(3; b=100)    # b=100
f(3; a=10, b=20)
50
  • ; の右側にあるのがキーワード引数
  • 呼び出し時も;の右側に名前 = 値 の形で渡す

注意: named argumentsは、定義したときのキーワードと使うときの変数の名前が一致していないと関数側が引数を受け取れません。

f(; w=3, h=2) や f(; w, h) はエラーになります。

配列

配列（Array）

  • インデックスは 1から始まる（PythonやCと違う点に注意）。
  • 1次元配列は列ベクトル
  • 各要素は,で区切る。
  • 2次元配列の各要素は空白で区切る。
  • 行を追加するなら;または改行を使う。
vec1 = [1, 2, 3]          # 1次元配列（ベクトル）
mat1 = [ [1 2 3]; [4 5 6] ]  # 2次元配列（2行3列の行列）
mat2 = [1.0 2.0 3.0
        0.0 4.0 5.0
        0.0 0.0 6.0] # 3×3行列

配列の要素にアクセスする

作った配列にアクセスするには配列の名前[]で指定します。

a = [1, 2, 3]        
b = [ [1 2 3]; [4 5 6] ]
a[2]
b[1] # 1が返ってくる
b[1, 1] #2次元以上は[縦方向のindex, 横方向のindex]で指定
1

2次元以上の時に

  • a[1]のように書くと「Linear index」となる
  • Linear indexは配列を1列に並べたときのindex。
  • a[1, 1]のように書くと「Cartesian index」となる
  • Cartesian indexは配列の次元ごとのindex。
2×3 Array Linear index Cartesian index
1 2 3 1 3 5 (1,1) (1,2) (1,3)
4 5 6 2 4 6 (2,1) (2,2) (2,3)

配列の要素に演算を行う

作った配列の各要素に演算を行う際は.(ドット演算子)を使います。

  • 演算子の前に . をつければ要素ごとに適用。
  • 例： a .* b, a .+ b, a ./ b
  • 関数も同様に sin.(a) のように . をつけると要素ごとに適用。
c = [5 4 3]
d = a.+ c # 各要素が6の行列にする
print(d)
sin.(c) # cの各要素にサイン関数を適用
[6 5 4; 7 6 5; 8 7 6]
1×3 Matrix{Float64}:
 -0.958924  -0.756802  0.14112

行列に対しても適用可能です。

I = [1 2 3;
     4 5 6]   # 2×3 行列

J = [10 20 30;
     40 50 60]  # 2×3 行列
I .+ J          # 要素ごとの和
I .* J          # 要素ごとの積
sin.(I)         # 各要素に sin を適用
2×3 Matrix{Float64}:
  0.841471   0.909297   0.14112
 -0.756802  -0.958924  -0.279415

タプル

  • ベクトルは角括弧 [] を使用して表記し、タプルは丸括弧 () を使用して表記します。
t = (1, 2, 3)
  • タプルもインデックスを通じて要素にアクセスできます。
t[1]
1

  • ベクトルとタプルは一見似ているように見えますが、重要な違いがあります。

    • タプルは不変(immutable)/配列は可変(mutable)
      • タプルの要素を変更することはできません。
      • ベクトルは形状を変えることができますが、タプルは不可能です。

Juliaの基礎: タプル

タプルには2種類あります。さっきのtは名前なしタプルです。

  1. 名前無しタプル
  2. 名前付きタプル
# 名前付きタプル
params = (
    α = 0.36,
    β = 0.99,
    δ = 0.025,
    ρ_z = 0.9,
    σ_z = 0.01
)
(α = 0.36, β = 0.99, δ = 0.025, ρ_z = 0.9, σ_z = 0.01)
params.β
0.99

t[1]でも呼べますが、名前付きタプルの特徴はt.nameのようにつけた名前で値を参照できることです。

for文

range

range(0, stop=1, length=5)  # 0.0, 0.25, 0.5, 0.75, 1.0

if文

if/elseif/else/end

の四つの要素に分かれます。

if 条件1
  戻り値
elseif 条件2
  戻り値
else if 条件3
  戻り値
...
else #それ以外
  戻り値
end #endで必ず閉じる
Num = 2.5
if Num > 3
    "big"
elseif 1 ≤ Num ≤ 3
    "medium"
else
    "small"
end
"medium"

while文

while文を使って「条件が満たされている間だけ」ループを続けるように計算させることができます。

function solve_cos_fixedpoint()
    x    = 1.0
    tol  = 1e-6
    diff = 1.0

    while diff > tol
        x_new = cos(x)
        diff  = abs(x_new - x)
        x     = x_new
    end
    return x
end

fixpoint = solve_cos_fixedpoint()
println("収束解 = $fixpoint")
収束解 = 0.7390855263619245

iterationなど、ある判定基準のところで計算を打ち切る場合に有用です。

ネスト（入れ子）と内包表記

for文と同じことを内包表記を使うと1行で書くことができます。

# for文と同じことを内包表記で
pairs = [(i,j) for i in 1:3 for j in 1:2]
println(pairs)
[(1, 1), (1, 2), (2, 1), (2, 2), (3, 1), (3, 2)]

内包表記の基本構文は [変数 for 変数 in 繰り返すインデックスの範囲] です。

繰り返すインデックスの範囲は、if文で条件をつけることができます。

# iが奇数、jが偶数のペアが返ってくるように条件を指定する
pairs2 = [(i,j) for i in 1:3 if i % 2 != 0 for j in 1:3 if j % 2 == 0]
println(pairs2)
[(1, 2), (3, 2)]

パッケージの使い方

パッケージのインストール

標準機能だけでは足りないときには外部ライブラリを利用することになります。

流れ:

  1. Pkg.add("PackageName") でインストール
  2. using PackageName で読み込み
  3. 実際に関数を使う
using Pkg
Pkg.add("Plots")
using Plots
plot([1,2,3], [4,5,6])

ターミナルでusing Pkg; Pkg.add("PackageName")を実行してパッケージをインストールすることもできます。

using パッケージの名前
Pkg.add("パッケージの名前")

はいったんやればその後は

using パッケージの名前

だけでパッケージを使うことが可能です。

データをプロットする

Plotsパッケージのインストール

using Pkg
Pkg.add("Plots")
using Plots

プロットの基本

  • plot(x, y; オプション...)
  • x: 横軸のデータ（ベクトルや配列）
  • y: 縦軸のデータ（同じ長さのベクトルや配列）
  • ; オプション... : タイトル、軸ラベル、色、凡例など

代表的なプロット関数

関数 説明
plot(x, y) 折れ線グラフ
scatter(x, y) 散布図
bar(x, y) 棒グラフ
histogram(x) ヒストグラム

よく使うオプション

  • title = "タイトル", xlabel = "X軸ラベル", ylabel = "Y軸ラベル"
  • legend = true 凡例表示
  • color = :blue 線や点の色
  • lw = 2 線の太さ (line width)
  • marker = :circle 散布図の点の形

など。Plots.jl はキーワード引数でカスタマイズできるのが特徴。

プロットの保存

  • PNG形式で保存 savefig("plot.png")

  • PDF形式で保存 savefig("plot.pdf")

  • SVG形式で保存（ベクター画像） savefig("plot.svg")

詳しくは、Plots.jlのサイトを参照

データをプロットする

棒グラフのプロット

avg_salary = combine(groupby(df, :Department), :Salary => mean => :AvgSalary) # 部署ごとの平均給与データを作成
